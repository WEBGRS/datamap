# DataMap

*[中文版](README.zh-CN.md)*

Paste two columns — a region and a number — and get a choropleth map with a palette that passes
accessibility checks. Covers US states, all 3,142 US counties, and 240 countries. A static page:
no backend, no CDN, works offline.

![US state GDP](docs/hero-us-gdp.png)

---

## What it solves

Coloring regions by a number normally means installing a GIS tool, hunting for a shapefile, and
hand-aligning region names. DataMap has all three built in:

| Problem | How it's handled |
|---|---|
| Finding geographic boundaries | TopoJSON basemaps (us-atlas / world-atlas) ship with the repo |
| Region names that don't match | Alias index covering English and Chinese names, ISO 2/3 codes, FIPS, abbreviations, and common informal names |
| Palettes that are ugly or unreadable | Scales are generated in OKLCH — single hue, monotonic lightness, validated for color-vision deficiency and contrast |
| Picking the wrong binning | Quantile, Jenks natural breaks, equal-interval, logarithmic, and symmetric-quantile, switchable in one click |

## Features

**Data input**

- Paste (comma, tab, or semicolon — Excel copy-paste works) or upload CSV/TSV
- Header detection, and a guess at which column holds regions and which holds values
- Forgiving number parsing: `$1,234.5万`, `7.2M`, `(1200)` for negatives, `3.5%`, `1.2亿`
- **Automatic basemap switching** — paste US state names while the world map is showing and it
  switches to US states
- Rows that fail to match are listed explicitly rather than dropped silently

**Region matching**

```
加州 / CA / California / 06 / 6          -> California
华盛顿特区 / Washington, D.C. / DC        -> District of Columbia
中国 / China / CN / CHN / 156             -> China
Korea, Rep. / South Korea / 韩国          -> South Korea
Côte d'Ivoire / Ivory Coast / 科特迪瓦    -> Côte d'Ivoire
```

**Color**

- Sequential scales: one hue, lightness stepping monotonically from 100 to 700, across 7 hues
- Diverging scales: warm and cool poles with a neutral grey midpoint; the center value is
  configurable
- Dark mode **re-anchors the ramp** so low values sit near the dark background, rather than
  inverting the light-mode colors
- 3 to 7 classes, or a continuous ramp
- Built-in **color-vision simulation**: protanopia, deuteranopia, tritanopia previews (preview
  only — exports are unaffected)

**Readability**

- A legend is always present, labeling every class boundary plus "no data"
- Hover readout: region name in both languages, value, and rank
- **Table view** — every color encoding has an equivalent sortable table, so color never carries
  information on its own
- Direct labels render only when the shape has room and the label doesn't collide with another
- Summary cards: regions covered, max, min, median, mean

**Export**: PNG (2x), SVG (styles inlined), CSV (the joined result)

## Quick start

```bash
npm install
npm start           # -> http://localhost:8123
```

Running it needs only `index.html`, `src/`, `data/`, and `vendor/`. Drop those on any static host.

## Layout

```
index.html
src/
  app.js        main program: state, render pipeline, panels, export
  color.js      OKLab/OKLCH conversion, scale generation, CVD simulation
  scales.js     binning (quantile / Jenks / equal-interval / log / symmetric-quantile) + number formatting
  parse.js      delimiter sniffing, quoted-CSV parsing, forgiving numbers
  match.js      region-name normalization and the alias index
  samples.js    generated sample data (do not hand-edit)
data/           TopoJSON basemaps + region alias tables (generated by build/)
vendor/         d3.min.js, topojson-client.min.js (vendored, no CDN)
build/          fetch and generation scripts, palette validation, browser smoke tests
```

## Rebuilding the data

```bash
npm run fetch     # download upstream sources (World Bank / Census / Wikipedia / ISO 3166)
npm run data      # generate data/*.json and src/samples.js
npm run check     # validate every scale: monotonic lightness, adjacent dE, CVD separation
npm run test      # Playwright smoke tests: every sample, every control, exports, narrow viewports
npm run regress   # regression: column switching, refresh persistence, clearing, continuous ramps, diverging distributions
```

`npm run check` covers 42 sequential scales (7 hues x 2 themes x 3 class counts) and 6 diverging
scales. It exits 0 only if all of them pass.

## Design constraints

The palettes are computed, not hand-picked:

- **Sequential means one hue with monotonic lightness.** Blue uses the reference palette's raw
  100-700 values; every other hue reuses the same L/C track with a different hue angle, so
  monotonicity holds by construction.
- **Diverging means warm and cool poles around a neutral grey midpoint.** Not two cool hues — a
  cool midpoint doesn't read as "no difference" — and never a rainbow.
- **No more than 7 classes.** Past that, adjacent classes stop being distinguishable, and that's
  the point where you should be reading the table instead.
- **Color never carries information alone.** The table view, the legend, and the hover readout all
  surface the same value.
- **Dark mode is a re-picked ramp, not an inversion.**

Scales are validated with the `dataviz` spec's `validate_palette.js --ordinal`, light and dark,
exit 0.
